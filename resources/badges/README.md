# OCL Badges

An OCL badge shows that you put community leadership into practice: you used an idea from the framework in a real community and reflected on what happened.

Badges are not exams or rankings. They recognise skills practised in the real world. Digital badges are issued through [Badgecraft](https://www.badgecraft.eu/en/projects/23156).

## How it works

Each module has three paths. Each path earns a different badge.

| Path | What you did |
|---|---|
| Self-guided | Worked through the module independently |
| Workshop | Took part in a live OCL session |
| Mentor | Guided others through the module |

You can earn all three badges for the same module as your role grows.

## How to claim

1. Finish the module and gather your evidence.
2. Go to the [OCL project on Badgecraft](https://www.badgecraft.eu/en/projects/23156).
3. Select the badge for your module and path → **Get this badge**.
4. Submit your evidence for review.

## What counts as evidence

Anything that shows you engaged with the module and connected it to real community practice — a completed canvas, workshop notes, a reflection, a change you tested, or facilitator notes. It does not need to be polished.

Evidence is reviewed for honest engagement, not writing quality or outcome.
